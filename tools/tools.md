# Tools and Libraries

## 1. Python

**Purpose:**
Python is used as the main programming language for data processing, machine learning, natural language processing, and citation analysis.

**Official Link:**
https://www.python.org/

## 2. Pandas

**Purpose:**
Pandas is used to load, clean, filter, transform, and analyze research-paper and citation datasets.

**Official Link:**
https://pandas.pydata.org/

## 3. Scikit-learn

**Purpose:**
Scikit-learn provides machine-learning algorithms and tools for preprocessing, classification, similarity analysis, model evaluation, and experimentation.

**Official Link:**
https://scikit-learn.org/

## 4. Hugging Face Transformers

**Purpose:**
Hugging Face Transformers provides pretrained transformer models that can be used for scientific natural language processing, text classification, information retrieval, and other NLP tasks.

**Official Link:**
https://huggingface.co/docs/transformers/

## 5. Sentence Transformers

**Purpose:**
Sentence Transformers can convert scientific text into numerical embeddings and calculate semantic similarity between citation contexts and research papers. This is useful for finding newer papers that are semantically similar to an existing citation.

**Official Link:**
https://sbert.net/

Sentence Transformers supports semantic similarity, semantic search, clustering, classification, and retrieval tasks.
