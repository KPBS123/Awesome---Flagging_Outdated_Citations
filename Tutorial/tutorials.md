# Tutorials and Learning Resources

## 1. Hugging Face NLP Course

**Author/Organization:** Hugging Face

**Purpose:**
This course provides practical learning material for natural language processing, transformers, tokenization, datasets, and model fine-tuning.

**Relevance to the Project:**
The course can help in learning how transformer-based NLP models can be applied to scientific text and citation analysis.

**Link:**
https://huggingface.co/learn/nlp-course/

## 2. Scikit-learn User Guide

**Author/Organization:** Scikit-learn

**Purpose:**
The Scikit-learn User Guide explains machine-learning algorithms, preprocessing, model selection, classification, clustering, and evaluation.

**Relevance to the Project:**
These methods can be used to build baseline models for detecting potentially outdated citations and evaluating recommendation performance.

**Link:**
https://scikit-learn.org/stable/user_guide.html

## 3. PyTorch Tutorials

**Author/Organization:** PyTorch

**Purpose:**
The official PyTorch tutorials provide step-by-step guidance for building, training, and evaluating deep-learning models.

**Relevance to the Project:**
PyTorch can be used to develop and fine-tune neural NLP models for citation classification and scientific-document analysis.

**Link:**
https://docs.pytorch.org/tutorials/

The official tutorials include beginner material, complete workflows, and practical examples.

## 4. Sentence Transformers Documentation and Quickstart

**Author/Organization:** Sentence Transformers

**Purpose:**
The documentation explains how to generate text embeddings, calculate similarity, perform semantic search, and build retrieval systems.

**Relevance to the Project:**
Semantic embeddings can be used to compare an existing citation with newer scientific papers and rank candidate replacement papers.

**Link:**
https://sbert.net/docs/quickstart.html

Sentence Transformers officially supports semantic similarity and semantic-search applications.

## 5. spaCy 101

**Author/Organization:** spaCy

**Purpose:**
spaCy 101 introduces important natural-language-processing concepts including tokenization, linguistic annotations, named entities, vectors, similarity, pipelines, and training.

**Relevance to the Project:**
These NLP techniques can help preprocess scientific text and citation contexts before applying machine-learning or retrieval methods.

**Link:**
https://spacy.io/usage/spacy-101

The official resource includes explanations and examples for NLP processing with spaCy.
